## [Unreleased]

حالت «پردازش کامل خودکار» — فاز ۱ نقشهٔ راه اتوماسیون.

### Added / اضافه شد
- **حالت پردازش کامل خودکار**: سوییچ «تعاملی / خودکار» روی صفحهٔ خانه و کارت
  «اتوماسیون» در تنظیمات (همراه سقف تلاش سینک). در حالت خودکار موتور pipeline
  بدون توقف برای تصمیم‌های عادی پردازش می‌کند؛ حالت تعاملی، رفتار قبلی است و
  پیش‌فرض می‌ماند.
- **لایهٔ سیاست بک‌اند (`pipeline/policy.rs`)**: چهار مانع تصمیم — چند Track
  فارسی، Track بی‌نشانه، کاندیدای مبهم آرشیو، چند sidecar — در حالت خودکار با
  قواعد قطعی و قابل‌توضیح حل می‌شوند؛ انتخابِ خودکار همان revalidation مسیر
  تعاملی را می‌گذراند و هیچ سیاستی تعارض یا بازنویسی را دور نمی‌زند.
- **امتیازدهی Track فارسی (`subtitle/scoring.rs`)**: تراکم حروف فارسی، پوشش
  زمانی نسبت به طول ویدیو، سلامت cue (خالی/تکراری/تبلیغ‌مانند)، و بونوس کوچکِ
  tag — نرمال‌شده با دلایل قابل‌نمایش. امتیاز فقط برای ترتیب‌دهی است (احتمال
  کالیبره‌شده نیست)؛ کاندیداهای هم‌امتیاز، کم‌شواهد یا زیر حداقل ۱۰ cue هرگز
  به‌صورت خودکار انتخاب نمی‌شوند — به «نیازمند بررسی» می‌روند.
- **وضعیت «نیازمند بررسی» (`NeedsReview`)**: موارد نامطمئن با دلیل صادقانه در
  شمارنده‌ها، خلاصهٔ اجرا و بخش «نیازمند بررسی» UI ظاهر می‌شوند — هیچ حدسِ
  کم‌اطمینانی به‌جای آن نمی‌نشیند.
- **سینک تطبیقی با سقف تلاش (حالت خودکار)**: نردبان استراتژی‌ها تا سقف قابل‌تنظیم
  (پیش‌فرض ۲، حداکثر ۴) اجرا و بهترین کاندیدای validated با شواهد کیفیت انتخاب
  می‌شود — توافق آفست دو تلاش مستقل (فاصلهٔ ≤۰٫۵s) قوی‌ترین شاهد است، بعد tier
  استراتژی؛ «کوچک‌ترین آفست» به‌تنهایی هرگز برنده نیست. گیت کیفیت ۳۰ ثانیه‌ای در
  هر دو حالت پین و پابرجاست. رکورد همهٔ تلاش‌ها (استراتژی/وضعیت/آفست/پذیرش) در
  جزئیات هر فایل نمایش داده می‌شود.
- **گزارش JSON ماندگار هر batch**: `%ProgramData%\SubSync Studio\data\runs\run-<run_id>.json`
  — نوشتن اتمیک، بدون بازنویسی، بدون هیچ secret؛ شامل ورودی‌ها، نتیجهٔ نهایی هر
  فایل، دلایل تصمیم‌های خودکار، رکورد تلاش‌های سینک و شمارش‌های خلاصه. شکست
  نوشتن گزارش فقط warning است و نتیجهٔ پردازش را خراب یا منکر نمی‌کند.

### Security / امنیت
- هیچ مسیر no-overwrite ضعیف نشده؛ انتخاب‌های خودکار دقیقاً همان revalidation
  مسیر تعاملی را می‌گذرانند و تعارض‌ها مثل قبل حفظ می‌شوند.
- probe امتیازدهی Track فقط داخل workspace موقت زیر temp اجرا و کامل پاک
  می‌شود؛ ویدیو و زیرنویس‌های کاربر هرگز تغییر نمی‌کنند.
- حالت خودکار هرگز به‌تنهایی آفست‌های بزرگ‌تر از گیت ۳۰s را «موفق» نمی‌کند.

## [0.2.8] — 2026-11-27

سینکِ دوباره قابل‌اعتماد شد — ریشهٔ واقعی شکست سینک روی رلیزهای ۶کاناله.

### Fixed / رفع شد
- **شکست همیشگیِ «کیفیت پایین» روی رلیزهای ۶کانالهٔ پر-موسیقی**: اسکور خامِ
  ffsubsync نرمال‌شده نیست و روی VAD کم‌بازده، پیک‌های کاذبِ بزرگ (۳۰–۶۰ ثانیه)
  پیدا می‌کرد که گیت کیفیت ردشان می‌کرد؛ سینک دوباره هم دقیقاً همان نتیجه را
  می‌داد (شواهد واقعی: چهار اجرای صوتی، چهار آفست متفاوت +36.11/+32.6/−8.64/−297
  برای همان فایل)
- **استراتژی چندمرحله‌ای سینک**: تلاش اول همیشه «مرجع کامل» است — ffsubsync خودش
  Track زیرنویس متنیِ داخلی ویدیو را مرجع می‌گیرد (هم‌ترازی زیرنویس‌به‌زیرنویس:
  پایدار، دقیق و بدون نویز صوت) و در نبود آن VAD کامل صوت؛ نمونه‌برداری صوت
  (رفتار قبلی) فقط fallback تلاش دوم است
- زیرنویس‌های از-قبل-سینک حالا با موفقیت و آفست ≈0 تمام می‌شوند (تأییدشده روی
  رسانهٔ واقعی)، نه marker «کیفیت پایین»
- هر تلاش پوشهٔ لاگ جداگانه دارد (ffsubsync لاگش را append می‌کند) و خروجی هر
  تلاش پیش از پذیرش دوباره اعتبارسنجی می‌شود
- نتیجهٔ «کیفیت پایین» حالا دلیل واقعی را نشان می‌دهد: کدام استراتژی‌ها و چه
  آفست‌هایی رد شدند

### Security / امنیت
- گیت کیفیت عمداً روی پیش‌فرض 30s پین ماند — بالا بردنش آفست‌های کاذب را
  «سینک موفق» می‌کرد؛ آفست‌های ردشده فقط گزارش می‌شوند و هیچ ورودی‌ای هرگز
  تغییر نمی‌کند
- تست‌های E2E رسانهٔ واقعی (گیت‌شده با متغیر محیطی): سناریوی sidecar هم‌نامِ
  ویدیو با Track داخلی سینک‌شده و کنترل مثبتِ شیفت +25s با ابزارهای واقعی

## [0.3.2] — 2026-11-28

- **دکمهٔ گروهی «استخراج زیرنویس‌ها»** کنار «هاردساب همهٔ موارد موفق» برای

- **شفافیت تنظیم دوباره**: جزئیات هر فایل حالا «روش سینک» را نشان می‌دهد
  (مرجع صوتی کامل / مرجع کامل / نمونه‌برداری صوت) — کاربر می‌بیند هر تلاش با
  چه روشی سینک شده؛ پاسخ سؤال: یادش می‌ماند (per-session)، بدون سقف تعداد،

### Fixed / رفع شد
- نوار پیشرفت روی ۱۰۰٪ می‌ماند و بعد ~۳۰ ثانیه ادامه می‌یافت — مرحلهٔ
  جانمایی/SoftSub هنوز کار داشت؛ حالا ۱۰۰٪ فقط پس از پایان واقعی اجراست

### Verified / راستی‌آزمایی
- تست E2E کامل real-world (رسانهٔ واقعی ۱٫۸GB + ابزارهای واقعی، ۱۱ دقیقه):
  pipeline SoftSub → استخراج زیرنویس معتبر فارسی → تنظیم دوباره با چرخش
  استراتژی به مرجع صوتی → SoftSub مجدد — هر سه مرحله سبز

## [0.3.0] — 2026-11-28

حلقهٔ سینک → پخش → قضاوت کاربر + پیشرفت یک‌نواری.

### Added / اضافه شد
- **حلقهٔ قضاوت کاربر برای سینک**: هر «تنظیم دوباره» با استراتژی متفاوتی سینک
  می‌کند (مرجع صوتی کامل → مرجع کامل → نمونه‌برداری صوت — با زیرنویس تازه) و
  پس از پایان، دکمهٔ «پخش ویدیو و بررسی سینک» با پخش‌کنندهٔ پیش‌فرض ویندوز
  می‌آید؛ اگر سینک درست نبود، تنظیم دوبارهٔ بعدی روش دیگر را می‌آموزد تا
  حلقه همگرا شود. انگیزه: پروب per-window روی رسانهٔ واقعی نشان داد هیچ
  سیگنال خودکاری روی صدای شلوغ نمی‌تواند «درست» را تضمین کند — قضاوت نهایی با
  چشم کاربر است
- **استراتژی مرجع صوتی کامل**: `--vad webrtc` مسیر زیرنویسِ داخلی را دور می‌زند
  و VAD کامل صوت — تنها شاهدِ مستقل از خودِ زیرنویس — مرجع می‌شود
- دکمهٔ «پخش» کنار هر فایل موفق در فهرست اجرا

### Changed / تغییر شد
- **پیشرفت یک‌نواری**: یک نوار + درصد بولد + زمان تقریبی باقی‌مانده (از نسبت
  elapsed/progress واقعی) — به‌جای چهار نوار و چند خط توضیح
- **خلاصهٔ پایان خلوت‌تر**: تیتر نتیجه + مدت + یک ردیف اقدام؛ شمارش‌ها و

## [0.2.8] — 2026-11-27

خروجی SoftSub به‌صورت پیش‌فرض / Persian SoftSub as the new default output.

### Added / اضافه شد
- **حالت خروجی SoftSub (پیش‌فرض جدید)**: زیرنویس فارسی سینک‌شده داخل خود ویدیو
  remux می‌شود (MKV: srt، MP4: mov_text، WebM: webvtt)؛ ویدیو/صدا و Trackهای
  دیگر بدون re-encode و بیت‌به‌بیت stream-copy می‌شوند
- انتخاب «نحوهٔ ذخیرهٔ زیرنویس» در تنظیمات: SoftSub (پیش‌فرض نسخه‌های جدید) یا
  فایل جدا کنار ویدیو (رفتار قبلی)؛ تنظیمات قدیمی بدون نسخهٔ این فیلد به‌صورت
  امن به SoftSub مهاجرت می‌شوند
- جایگزینی امن Track داخلی فارسی: Track تأییدشده حذف و نسخهٔ سینک‌شده جای همان
  Track می‌نشیند تا دو Track فارسی هم‌زمان وجود نداشته باشد؛ Trackهای داخلی
  مبهم → تصمیم صریح کاربر
- remux اتمیک با backup/rollback: خروجی اول در پوشهٔ موقتِ هم-volume ساخته
  می‌شود؛ در شکست یا لغو، ویدیوی اصلی همیشه بیت‌به‌بیت دست‌نخورده می‌ماند و
  کاندیدا برای بازیابی حفظ می‌شود
- شمارنده و نتیجهٔ جدید «SoftSub شد» در خلاصهٔ pipeline و UI
- فایل‌های میانی زیرنویس (استخراج/دانلودی) پس از mux موفق پاک می‌شوند تا
  sidecar اضافه ساخته نشود؛ فایل‌های قبلی کاربر هرگز حذف نمی‌شوند
- هارنس اعتبارسنجی real-world (گیت‌شده با متغیر محیطی): pipeline واقعی با
  FFmpeg/FFprobe/FFsubsync واقعی روی کپی‌های ایزوله رسانهٔ واقعی — CI هرگز
  اجرایش نمی‌کند

### Security / امنیت
- هیچ بازنویسی درجایی روی ویدیو انجام نمی‌شود: نصب خروجی فقط با rename اتمیک
  پس از backup و با گارد تغییر هم‌زمان فایل (size/mtime/symlink)
- workflow ریلیز: نام نصاب از نسخهٔ tauri.conf.json خوانده می‌شود (بدون مسیر
  هاردکد)

## [0.1.0] — 2026-11-19

اولین ریلیز عمومی / First public release.

### Added / اضافه شد
- **pipeline کامل زیرنویس فارسی** در ۱۲ مرحله: اعتبارسنجی → اسکن → بررسی sidecarها →
  تحلیل → استخراج داخلی → دانلود SubSource → آرشیوها → انتخاب ورودی سینک →
  همگام‌سازی ffsubsync → جانمایی → پایان؛ با دیالوگ‌های تصمیم صریح کاربر
- **معاونت راه‌اندازی اولین اجرا** — دانلود و نصب خودکار ffmpeg 8.0 + Python 3.11.9 +
  ffsubsync 0.5.1 (per-user، بدون admin، با تأیید SHA256 پین‌شده، progress واقعی و لغو)
- استخراج زیرنویس داخلی با تشخیص فارسی دو لایه (tag + تأیید محتوا) و اعتبارسنجی خروجی
- دانلود از SubSource با staging امن (hard link) و کدهای skip تایپ‌شده
- تطبیق و استخراج آرشیوها (zip/rar/7z) با تطبیق اپیزود و حفظ تعارض‌ها
- همگام‌سازی با ffsubsync: multi-segment، skip-intro-outro، محافظت کیفیت پایین،
  آفست اعتبارسنجی‌شده در UI
- جانمایی no-overwrite: خروجی `<نام>.fa.synced.srt` کنار ویدیو
- پیشرفت مرحله‌ای و نتیجهٔ فوری هر فایل در UI — هیچ درصدی ساختگی نیست
- لغو امن هر عملیات، بازیابی وضعیت پس از بستن/reload برنامه
- کارت شتاب: افزودن یک‌کلیکی به استثناهای Windows Defender + میان‌بر Run-as-admin
- نصاب NSIS ویندوز + workflow ریلیز خودکار گیت‌هاب (تگ → build + SHA256 + Release)

### Security / امنیت
- کلید API SubSource فقط در Windows Credential Manager
- تأیید SHA256 همهٔ دانلودهای خودکار؛ باندل‌ها فقط از نصاب رسمی برنامه
- هیچ عملی elevated بدون رضایت صریح کاربر اجرا نمی‌شود
