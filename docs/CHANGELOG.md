## [0.2.8] — 2026-11-27

سینکِ دوباره قابل‌اعتماد شد — ریشهٔ واقعی شکست سینک روی رلیزهای ۶کاناله.

### Fixed / رفع شد
- **شکست همیشگیِ «کیفیت پایین» روی رلیزهای ۶کانالهٔ پر-موسیقی**: اسکور خامِ
  ffsubsync نرمال‌شده نیست و روی VAD کم‌بازده، پیک‌های کاذبِ بزرگ (۳۰–۶۰ ثانیه)
  پیدا می‌کرد که گیت کیفیت ردشان می‌کرد؛ سینک دوباره هم دقیقاً همان نتیجه را
  می‌داد (شواهد واقعی: چهار اجرای صوتی، چهار آفست متفاوت +36.11/+32.6/−8.64/−297
  برای همان فایل)
- **استراتژی چندمرحله‌ای سینک**: تلاش اول همیشه «مرجع کامل» است — ffsubsync خودش
  Track زیرنویس متنیِ داخلی ویدیو را مرجع می‌گیرد (هم‌ترازی زیرنویس‌به‌زیرنویس:
  پایدار، دقیق و بدون نویز صوت) و در نبود آن VAD کامل صوت؛ نمونه‌برداری صوت
  (رفتار قبلی) فقط fallback تلاش دوم است
- زیرنویس‌های از-قبل-سینک حالا با موفقیت و آفست ≈0 تمام می‌شوند (تأییدشده روی
  رسانهٔ واقعی)، نه marker «کیفیت پایین»
- هر تلاش پوشهٔ لاگ جداگانه دارد (ffsubsync لاگش را append می‌کند) و خروجی هر
  تلاش پیش از پذیرش دوباره اعتبارسنجی می‌شود
- نتیجهٔ «کیفیت پایین» حالا دلیل واقعی را نشان می‌دهد: کدام استراتژی‌ها و چه
  آفست‌هایی رد شدند

### Security / امنیت
- گیت کیفیت عمداً روی پیش‌فرض 30s پین ماند — بالا بردنش آفست‌های کاذب را
  «سینک موفق» می‌کرد؛ آفست‌های ردشده فقط گزارش می‌شوند و هیچ ورودی‌ای هرگز
  تغییر نمی‌کند
- تست‌های E2E رسانهٔ واقعی (گیت‌شده با متغیر محیطی): سناریوی sidecar هم‌نامِ
  ویدیو با Track داخلی سینک‌شده و کنترل مثبتِ شیفت +25s با ابزارهای واقعی

## [0.2.0] — 2026-11-20

خروجی SoftSub به‌صورت پیش‌فرض / Persian SoftSub as the new default output.

### Added / اضافه شد
- **حالت خروجی SoftSub (پیش‌فرض جدید)**: زیرنویس فارسی سینک‌شده داخل خود ویدیو
  remux می‌شود (MKV: srt، MP4: mov_text، WebM: webvtt)؛ ویدیو/صدا و Trackهای
  دیگر بدون re-encode و بیت‌به‌بیت stream-copy می‌شوند
- انتخاب «نحوهٔ ذخیرهٔ زیرنویس» در تنظیمات: SoftSub (پیش‌فرض نسخه‌های جدید) یا
  فایل جدا کنار ویدیو (رفتار قبلی)؛ تنظیمات قدیمی بدون نسخهٔ این فیلد به‌صورت
  امن به SoftSub مهاجرت می‌شوند
- جایگزینی امن Track داخلی فارسی: Track تأییدشده حذف و نسخهٔ سینک‌شده جای همان
  Track می‌نشیند تا دو Track فارسی هم‌زمان وجود نداشته باشد؛ Trackهای داخلی
  مبهم → تصمیم صریح کاربر
- remux اتمیک با backup/rollback: خروجی اول در پوشهٔ موقتِ هم-volume ساخته
  می‌شود؛ در شکست یا لغو، ویدیوی اصلی همیشه بیت‌به‌بیت دست‌نخورده می‌ماند و
  کاندیدا برای بازیابی حفظ می‌شود
- شمارنده و نتیجهٔ جدید «SoftSub شد» در خلاصهٔ pipeline و UI
- فایل‌های میانی زیرنویس (استخراج/دانلودی) پس از mux موفق پاک می‌شوند تا
  sidecar اضافه ساخته نشود؛ فایل‌های قبلی کاربر هرگز حذف نمی‌شوند
- هارنس اعتبارسنجی real-world (گیت‌شده با متغیر محیطی): pipeline واقعی با
  FFmpeg/FFprobe/FFsubsync واقعی روی کپی‌های ایزوله رسانهٔ واقعی — CI هرگز
  اجرایش نمی‌کند

### Security / امنیت
- هیچ بازنویسی درجایی روی ویدیو انجام نمی‌شود: نصب خروجی فقط با rename اتمیک
  پس از backup و با گارد تغییر هم‌زمان فایل (size/mtime/symlink)
- workflow ریلیز: نام نصاب از نسخهٔ tauri.conf.json خوانده می‌شود (بدون مسیر
  هاردکد)

## [0.1.0] — 2026-11-19

اولین ریلیز عمومی / First public release.

### Added / اضافه شد
- **pipeline کامل زیرنویس فارسی** در ۱۲ مرحله: اعتبارسنجی → اسکن → بررسی sidecarها →
  تحلیل → استخراج داخلی → دانلود SubSource → آرشیوها → انتخاب ورودی سینک →
  همگام‌سازی ffsubsync → جانمایی → پایان؛ با دیالوگ‌های تصمیم صریح کاربر
- **معاونت راه‌اندازی اولین اجرا** — دانلود و نصب خودکار ffmpeg 8.0 + Python 3.11.9 +
  ffsubsync 0.5.1 (per-user، بدون admin، با تأیید SHA256 پین‌شده، progress واقعی و لغو)
- استخراج زیرنویس داخلی با تشخیص فارسی دو لایه (tag + تأیید محتوا) و اعتبارسنجی خروجی
- دانلود از SubSource با staging امن (hard link) و کدهای skip تایپ‌شده
- تطبیق و استخراج آرشیوها (zip/rar/7z) با تطبیق اپیزود و حفظ تعارض‌ها
- همگام‌سازی با ffsubsync: multi-segment، skip-intro-outro، محافظت کیفیت پایین،
  آفست اعتبارسنجی‌شده در UI
- جانمایی no-overwrite: خروجی `<نام>.fa.synced.srt` کنار ویدیو
- پیشرفت مرحله‌ای و نتیجهٔ فوری هر فایل در UI — هیچ درصدی ساختگی نیست
- لغو امن هر عملیات، بازیابی وضعیت پس از بستن/reload برنامه
- کارت شتاب: افزودن یک‌کلیکی به استثناهای Windows Defender + میان‌بر Run-as-admin
- نصاب NSIS ویندوز + workflow ریلیز خودکار گیت‌هاب (تگ → build + SHA256 + Release)

### Security / امنیت
- کلید API SubSource فقط در Windows Credential Manager
- تأیید SHA256 همهٔ دانلودهای خودکار؛ باندل‌ها فقط از نصاب رسمی برنامه
- هیچ عملی elevated بدون رضایت صریح کاربر اجرا نمی‌شود
